Welcome to the repository for my professional portfolio website and interactive educational articles. This project serves as a showcase of my research in quantitative macroeconomics, cognitive science systems, and modern web development.

## 🌟 Key Features

### 1. **Interactive Portfolio Home (`index.html`)**
* **Matrix Digital Rain Background:** A high-performance, optimized canvas-based Matrix rain animation running at a capped 30 FPS to conserve CPU.
* **Modern Developer Design:** Glassmorphic layout, clean grid spacing, hover-triggered interactive animations, responsive hamburger navigation menu, and CSS-based toast notifications.
* **Thailand Dev Attribution:** A customized footer showcasing localized developer credit with a subtle, pulsing CSS keyframe heart animation.

### 2. **Cognitive Science & Simulators (`mental_models.html`)**
A comprehensive educational guide covering Charlie Munger's core mental models, complete with three interactive sliders to visualize mathematical and behavioral concepts:
* 📈 **Interactive Compounding Simulator:** Visualizes the power of daily habits. Slide between -2% and +2% daily change to see the 365-day compounding curve ($1.01^{365} \approx 37.78\text{x}$ vs. $0.99^{365} \approx 0.03\text{x}$) mapped out on a dynamic vertical chart.
* ⏳ **Parkinson's Law Task Simulator:** Slides task deadlines (1 to 10 days) to calculate and display the corresponding changes in focus level, stress level, and output quality.
* ⚖️ **Pareto Principle Simulator:** Demonstrates the 80/20 rule of effort vs. results with a responsive ratio calculator.

### 3. **The Ten Principles of Economics (`principles_of_economics.html`)**
An academic-style research publication detailing N. Gregory Mankiw's foundational framework of economics.
* Dissects decision-making, market interactions (such as surge pricing and externalities), and macroeconomic systems.
* Designed with clean, readable academic typography, distinct highlight callouts, and structured sections.

## 🚀 Getting Started

### Local Setup
Since this project is built entirely on native web technologies, no build steps or bundlers are required.
1. Clone the repository:
   ```bash
   git clone https://github.com/Taesiwat/dataxbysiwat.git
   ```
2. Open `index.html` directly in your web browser, or serve it using any local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (npx)
   npx serve .
   ```
3. Navigate to `http://localhost:8000` or the corresponding local server port.
